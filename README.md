# Bitkub Automated Trading Bot 🤖📈 (บอทเทรดคริปโตอัตโนมัติบน Bitkub)

บอทเทรดคริปโตอัตโนมัติภาษา Python สำหรับใช้งานกับเว็บบอร์ดเทรด Bitkub Exchange รองรับการดึงข้อมูลราคาล่าสุด แท่งเทียนย้อนหลัง คำนวณอินดิเคเตอร์ทางเทคนิค (SMA, RSI) และส่งสัญญาณซื้อขายอัตโนมัติผ่านระบบ API V3/V4 ล่าสุด

บอทนี้มี **ระบบจำลองการลงทุน (Dry-run / Paper Trading)** ในตัว ทำให้คุณสามารถเริ่มต้นรันบอททดสอบเพื่อดูการคำนวณและคำสั่งจำลองได้ทันทีโดยไม่ต้องใช้ API Key จริงหรือเงินจริง ปลอดภัย 100%!

---

## โครงสร้างโปรเจกต์ (Project Structure)
*   `requirements.txt` - รายการไลบรารีที่บอทต้องการใช้งาน
*   `.env` - ไฟล์เก็บรหัสผ่าน API Key/Secret และการตั้งค่าระบบหลัก
*   `config.py` - สคริปต์โหลดและตรวจสอบความถูกต้องของการตั้งค่าในระบบ
*   `bitkub_client.py` - ไลบรารีสำหรับต่อตรงเข้า Bitkub API (ทั้งการขอเวลาเซิร์ฟเวอร์, ถอดรหัสลายเซ็น HMAC-SHA256, เช็คยอดกระเป๋าเงิน และส่งคำสั่ง)
*   `strategy.py` - ส่วนการคำนวณกลยุทธ์การเทรด (มีทั้ง SMA Crossover และ RSI เกินเขต)
*   `bot.py` - สคริปต์รันบอทหลักที่ทำงานวนซ้ำอย่างต่อเนื่อง

## วิธีการติดตั้งและเริ่มต้นใช้งาน (Installation & Quick Start)

### 1. การเตรียมสภาพแวดล้อมระบบ (Python Setup)
เครื่องคอมพิวเตอร์ของคุณต้องติดตั้ง **Python 3.8 ขึ้นไป** หลังจากนั้นให้เปิด terminal/command prompt ที่โฟลเดอร์ของโปรเจกต์นี้ แล้วติดตั้งไลบรารีที่เกี่ยวข้อง:

```bash
pip install -r requirements.txt
```

### 2. การกำหนดการตั้งค่าระบบ (Configuration)
เปิดไฟล์ `.env` ในโฟลเดอร์โปรเจกต์เพื่อตั้งค่าบอทของคุณ:

```ini
# Bitkub API Credentials (สมัครและรับสิทธิ์ Read, Trade จาก bitkub.com)
BITKUB_API_KEY=your_api_key_here
BITKUB_API_SECRET=your_api_secret_here

# การตั้งค่าการเทรด
SYMBOL=btc_thb
TRADE_AMOUNT_THB=50.0

# กลยุทธ์การเทรดที่เลือกใช้งาน: sma_crossover หรือ rsi
STRATEGY=sma_crossover

# โหมดรันจำลอง (True = บอทจำลองการเข้าเทรดโดยไม่ใช้เงินจริง, False = ซื้อขายจริงด้วยเงินจริง)
DRY_RUN=True

# ความถี่ในการทำงานของบอทในการวิเคราะห์ราคา (เป็นวินาที)
LOOP_INTERVAL_SECONDS=60
```

> [!WARNING]
> สำหรับการใช้งานเทรดจริง (**DRY_RUN=False**):
> - คุณต้องใส่ API Key และ API Secret ของบัญชี Bitkub จริงของคุณ
> - บัญชีและ Key ของคุณต้องเปิดสิทธิ์ **Read (อ่านข้อมูล)** และ **Trade (ซื้อขาย)** เท่านั้น
> - **ห้ามเปิดสิทธิ์ Transfer/Withdraw (โอน/ถอนเหรียญ) โดยเด็ดขาด** เพื่อความปลอดภัยของสินทรัพย์

## วิธีการรันบอท (Running the Bot)

เมื่อตั้งค่าในไฟล์ `.env` เรียบร้อยแล้ว สามารถสั่งรันบอทหลักได้ทันทีด้วยคำสั่ง:

```bash
python bot.py
```

### สิ่งที่จะเกิดขึ้นเมื่อบอททำงาน:
1. บอทจะทำการตรวจสอบความถูกต้องของค่าต่างๆ และเชื่อมโยงไปดึงข้อมูลราคาสินทรัพย์ปัจจุบัน
2. บอทดึงประวัติแท่งเทียน (OHLCV) ล่าสุดจากเซิร์ฟเวอร์
3. ทำการวิเคราะห์สัญญาณเทรดตามกลยุทธ์ที่เลือก (`sma_crossover` หรือ `rsi`)
4. ดำเนินการออกคำสั่งเทรดจำลอง (หาก `DRY_RUN=True`) หรือออกคำสั่งจริงไปยัง Bitkub (หาก `DRY_RUN=False`)
5. รอเวลาหน่วงตามที่กำหนดในลูป และวนลูปทำงานขั้นตอนเดิมต่อไปเรื่อยๆ (หยุดการทำงานได้ด้วยปุ่ม `Ctrl + C`)

## รายละเอียดกลยุทธ์ทางเทคนิค (Strategies)

### 1. SMA Crossover (`sma_crossover`)
*   **เส้นที่ใช้:** Simple Moving Average 5 วัน (Fast SMA) และ 20 วัน (Slow SMA)
*   **สัญญาณซื้อ (BUY):** เมื่อเส้น Fast SMA ตัดผ่านขึ้นสูงกว่า Slow SMA (ตลาดมีทิศทางขาขึ้น)
*   **สัญญาณขาย (SELL):** เมื่อเส้น Fast SMA ตัดผ่านลดลงต่ำกว่า Slow SMA (ตลาดมีทิศทางขาลง)

### 2. RSI Threshold (`rsi`)
*   **พารามิเตอร์:** RSI (14 วัน)
*   **สัญญาณซื้อ (BUY):** เมื่อ RSI ต่ำกว่าหรือเท่ากับ 30 (Oversold หรือเขตขายมากเกินไป) ซึ่งบ่งบอกว่าสินทรัพย์นั้นกำลังมีราคาต่ำและมีโอกาสพลิกตัว
*   **สัญญาณขาย (SELL):** เมื่อ RSI สูงกว่าหรือเท่ากับ 70 (Overbought หรือเขตซื้อมากเกินไป) ซึ่งบ่งบอกว่าราคาสินทรัพย์เพิ่มขึ้นสูงเกินไปและเสี่ยงต่อการกลับทิศเป็นขาลง
